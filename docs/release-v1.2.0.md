# PhoneTwin Studio v1.2.0 · 网页真机连接

公开工作台现在能通过运行在同一台 Windows 电脑上的接收端展示 iPhone 屏幕与姿态。首页 Showcase 与已有运镜不变。

## 使用

1. 更新到本版本，退出旧版后打开安装版或免安装版。
2. 在这台电脑浏览器打开 https://awoele.github.io/PhoneTwin-Studio/workbench/ ，点击连接图标 → 连接此电脑。
3. 在本机授权窗口确认网站来源后点击允许，保持窗口打开。网页显示 Sender 二维码，手机扫码、准备会话，并开启 PhoneTwin Broadcast。
4. 展示结束点击断开、撤销或关闭授权窗口。网页刷新需再次授权，已保存的正面校准仍保留。

手机和电脑需同一可信 Wi-Fi。iPhone Sender 仍通过原项目 TestFlight 分发；本次不重新分发 IPA。无公网中转、不需要端口映射；手机浏览器不能替代 Windows 接收端。

## 实现与边界

- 本机授权窗口仅在 127.0.0.1:5197 提供；来源、窗口身份与随机会话标识同时验证，不扩大 CORS 权限。
- 授权不持久化，撤销/关闭/连接失联即停止。只接受官方 GitHub Pages 来源。
- 二进制帧转移给网页，背压时保留最新帧；复用原有屏幕解码、姿态平滑和校准管线。
- 保留桌面工作台原有局域网方式、二维码与其他功能。
- 已通过 42 项自动化测试，包括模拟屏幕、姿态、重连、背压和来源校验；不把模拟测试视作当前 iPhone 的真机验收。
- 安装包未商业签名，可能显示未知发布者。仅从本仓库下载并核对 SHA-256，不关闭系统安全防护。
