# PhoneTwin Studio 使用指南

## 下载与启动

在 [Releases](https://github.com/awoele/PhoneTwin-Studio/releases/latest) 中选择 Setup 安装版或 Portable 免安装版。无需手动启动服务器；打开软件即可显示工作台并启动手机接收服务。

打开后选择“连接 iPhone”，显示的二维码自动使用当前电脑的局域网地址。在手机 Sender 中扫码、准备会话，并开启 PhoneTwin Broadcast 屏幕广播。详细顺序见仓库首页。

## 工作台操作

- 拖动旋转手机，滚轮缩放；“手机与视角”可保存固定视角。
- “场景”切换四种动态背景和灯光。
- “镜头导演”选择镜头序列或编辑路径，点击保存预设；保存只影响当前电脑。
- v1.1 可先载入“产品揭幕 / 机身巡礼 / 屏幕叙事”，在时间线用 ↑↓ 排序，并分别设置运动秒数、停留秒数和节奏；点击“应用并播放编排”才生效。播放时修改的是草稿，不重启正在播放的版本；速度按钮仍可实时调速。多段镜头保留配方缓动，可修改时长。
- “保存当前预设”会保存各镜头设置，刷新后恢复；旧版预设仍可用。录制中按 P 同样采用当前编排，只播放一遍。
- 录制后按 **P** 播放一次已设置的镜头，再手动停止并保存视频。
- 默认录制工作台窗口，包含背景；取消“包含工作台背景”则只录制 3D 画布。电脑端仅捕获工作台自己的窗口，不捕获其他应用。
- 全屏时可保留所需工具与标签。
- 导入图片/视频只在本地读取；上传到公开工作台也不会将媒体发送到服务器。

## 连不上或没有手机画面

1. 先确认电脑端显示接收服务已运行；不要同时启动多个工作台或旧命令行服务。
2. 电脑和手机使用同一 Wi-Fi，避免访客网络、无线客户端隔离；VPN/虚拟网卡可能让自动地址选错，必要时使用 Windows 网络设置里 Wi-Fi 的 IPv4 手动填写。
3. 防火墙只允许该应用在可信的专用网络通信。需要的手机入口为 TCP 8788；不要在路由器上配置公网端口映射。
4. 有姿态但没有屏幕：确认系统广播选的是 PhoneTwin Broadcast，手机没有锁屏、广播未停止。部分受保护视频可能被 iOS 阻止采集。
5. 断线后先停止广播，在 Sender 中重新准备会话，再开启广播；已保存校准无需重复设置。
6. 如提示端口占用，先退出其他 PhoneTwin 软件再重开，不要随机结束系统进程。
7. 卡顿时优先使用信号稳定的 Wi-Fi，减少并行视频传输；旋转跟手选“即时”或“跟手”。该设置不能消除网络传输延迟。

## 数据与隐私

真机画面和姿态在当前局域网传输，不需要公共中转服务器。仅在可信网络使用，演示前关闭通知并避免展示敏感内容。当前接收协议不提供强认证，不适合访客网络、共享公共网络或公网暴露。

iPhone Sender 由原项目通过 TestFlight 分发。邀请、测试人数及构建有效期由上游控制；如失效，需等待上游更新，或使用自己的 Apple 开发者签名构建，不能通过普通 GitHub IPA 下载绕过 iOS 签名。
