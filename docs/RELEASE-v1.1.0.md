# PhoneTwin Studio v1.1.0 · 导演编排

- 新增弧线巡礼、俯仰揭幕、蓄力慢推、拉远定版，总计 10 种镜头。
- 新增产品揭幕、机身巡礼、屏幕叙事三组成组编排，载入后仍可编辑。
- 时间线支持上移、下移、移除镜头，分别设置运动时长、停留与节奏。
- 应用时锁定播放版本，编辑草稿不会打断当前镜头；暂停继续沿用进度。
- 保留 v1.0 的预设、路径、P 录制快捷键与真机连接方式。

镜头语言参考 [video-shotcraft](https://github.com/Vincentwei1021/video-shotcraft)，
适配为实时 3D 手机运镜，不包含 Remotion 视频生成、音乐卡点或剪映工程导出。
弧线巡礼不冻结手机投屏画面，镜头始终保留整机入画保护。
