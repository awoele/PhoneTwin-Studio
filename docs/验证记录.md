# v1.0.0 验证范围

- Windows 本机构建成功，生成安装版和免安装版，包含 Electron 运行环境。
- 28 项自动化测试通过，覆盖校准记忆、镜头轨迹、录制快捷键、最新帧队列、重连与桌面服务转发。
- 打包后的程序启动接收服务，无需外部 Node；测试客户端通过电脑端 WebSocket 代理收到姿态 JSON 与二进制帧。
- 局域网地址接口、模型文件响应、SSE 状态通道及跨来源请求拒绝已检查。
- iPhone Sender 的上游 TestFlight 入口由项目作者确认可安装。

上述传输测试使用模拟 Sender，不代表已在接收方的 iPhone 和 Wi-Fi 上完成实测。对方首次使用仍需按指南允许局域网权限、连接并开启屏幕广播。录制兼容性、实际无线延迟及 TestFlight 后续有效期以接收方设备为准。
