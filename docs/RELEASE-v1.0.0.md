# PhoneTwin Studio v1.0.0

Windows 10/11 x64 桌面工作台，可连接同一 Wi-Fi 下的 iPhone。

## 下载

- `PhoneTwin-Studio-1.0.0-Setup-x64.exe`：安装版，推荐使用。
- `PhoneTwin-Studio-1.0.0-Portable-x64.exe`：免安装版，首次解压启动稍慢。
- `SHA256SUMS.txt`：安装包校验值。

内置运行环境，打开即自动启动手机接收服务，无需安装 Node 或手动执行命令。

## 手机端

iPhone 使用原项目的 [PhoneTwin Sender TestFlight](https://testflight.apple.com/join/EFpEgJfW)，邀请由上游维护，本项目作者已确认可安装，仅用于非商用试用/演示。

先阅读 [下载安装与连接](https://github.com/awoele/PhoneTwin-Studio#下载安装) 和 [使用指南](https://github.com/awoele/PhoneTwin-Studio/blob/main/docs/使用指南.md)。电脑和手机需连接同一可信 Wi-Fi，手机开启 PhoneTwin Broadcast 屏幕广播。

## 注意

安装包未使用商业代码签名证书。只从本仓库下载并核对 SHA-256；无需关闭防火墙或系统安全软件。首次允许应用通过可信专用网络通信。

工作台支持镜头编排、动态场景、灯光、媒体导入和录制；不是手机远程控制工具。上游 TF 构建有效期和名额不由本项目控制。
